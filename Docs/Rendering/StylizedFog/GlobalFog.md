# 全局体积雾入口

放置一个 **YOG 全局体积雾**（`AYogNinjaGlobalFogActor`）即可启用全屏世界空间雾，不需要放置、缩放或绑定局部雾容器。Actor 的位置和缩放不限定雾的覆盖区域。

## 使用

1. 新关卡：在「放置 Actor」的全部类中搜索「YOG 全局体积雾」并拖进关卡；也可执行 `Yog.NinjaFog.Open`，点击「添加 / 选择全局雾」。已有旧 Ninja 雾的关卡需要先切换：退出 PIE / SIE，在工作台点击「切换当前场景到全局雾（停用旧容器）」，或执行 `Yog.NinjaFog.UseGlobal`。
2. 在主编辑器 Details 中设置地面世界高度、高度衰减尺度、雾密度及颜色。密度从地面开始连续向上变稀，没有固定雾顶；编辑状态打开视口实时更新可预览。
3. 玩家与局部灯光退雾自动工作。默认继承已验收的地面浓雾、上层雾量与清雾参数，无需绑定 FogCarrier。
4. 在「预览」中设置通道：0 成图、1 雾遮罩、2 流向、3 受光。

切换会复用当前世界已启用、优先级最高的全局雾；没有时，在旧雾所属关卡新建，并带入关联环境控制器的地面、玩家/灯光清雾与缓存参数。它仅停用当前启用且带 `YogNinjaSmokeExact` 标签的旧容器及关联环境控制器，停止旧输入预览，保留 Actor 与资产以便回退；可通过编辑器「撤销」恢复。新建时若场景已有同一雾后 Finish，会自动避免重复叠加。

切换不自动保存。检查效果后，保存本次修改且由你负责的关卡（旧容器与控制器若分属不同关卡，也需保存对应关卡），下次打开才会保持切换结果。

## 主要参数

| 分组 | 控制 |
|---|---|
| 全局雾 | 开关、密度、高度衰减尺度、最大渲染距离、暗部/亮部颜色 |
| 云团与流动 | 世界空间云团尺寸、厚薄对比、交界翻卷幅度/速度、交界细节、输入动画 |
| 地面雾体 | 地面世界高度、贴地高度、贴地/上层雾量、距离场接触影响 |
| 玩家清雾 | 半径、强度、羽化和垂直范围 |
| 灯光清雾 | 强度、半径上限、羽化；自动选择附近最多四个有效局部灯 |
| 体积受光 | 主光颜色、强度、方向、自阴影；可绑定一个位置 Actor 作为点主光 |
| 描边与笔触 | 场景结构线、外围笔触强度和疏密、雾内笔触 |
| 渲染质量 | 视线最大步数、自阴影步数、环境缓存分辨率/层数/频率 |

「高度衰减尺度」是半密度高度，默认 450 厘米：相对地面升高 450 / 900 / 1350 厘米，高度密度系数分别为 50% / 25% / 12.5%，之后继续变稀。它与贴地/上层雾量相乘，玩家和灯光退雾继续参与；旧「顶部柔化」参数不再参与全局雾。

全局入口隐藏并关闭旧容器的「空间高度」封顶选项，加载旧实例也不会重新带入有限雾顶。关闭环境交互时，地面世界高度仍控制全局高度衰减。

「最大渲染距离」是每个视图的射线积分距离。「交互缓存半径」仅控制距离场交互缓存的覆盖与精度，缓存之外仍渲染全局雾，并使用连续的地面/玩家/灯光解析系数。缓存边缘做平滑混合，不把缓存当作渲染体积盒。

默认视线最大步数 32，自阴影 6 步，环境缓存 128×128×16 / 10 Hz，Ninja 密度与速度输入 256² / 最高 30 Hz。实际视线步数依据积分长度自适应，并覆盖完整可见线段。

## 实现

- 无 StaticMesh、ChildActor 或 BoxVolume；两个 Unbound PostProcessComponent 分别承载全局雾和可选 Finish。
- 全局雾仍沿世界射线积分密度、透射率和自身阴影，用不透明场景深度终止射线。视线不再与雾顶平面求交，视线和阴影使用相同的连续指数高度函数。非均匀视线采样向近地高密度区域集中，并使用每个区间的真实长度进行积分。世界坐标固定的 XYZ 云团与二维 Ninja signed RG / B 输入共同提供形态和局部流动。
- 复用现有环境 Compute 缓存；新 Actor 只提供自动量化移动的缓存域与自身 MID，原局部容器的绑定和域计算路径保留。
- 全局雾位于 SceneColorAfterDOF、TAA/TSR 之前，让时间抗锯齿处理随机步进颗粒；结构线与外围笔触仍在 BeforeBloom 保持清晰。
- 同一世界仅使用启用且优先级最高的全局 Actor；同优先级按对象路径选择，避免重复合成。编辑器和 PIE 资源分别创建。删除、禁用或撤销只处理本 Actor 的资源和后处理组件。
- Actor 开关不修改项目的 `r.VolumetricFog`，本入口使用项目自己的全局 raymarch，并非切换成 UE 原生 froxel 雾。

## 资源与验证范围

材质为 `/YogVision/Global/M_NinjaGlobalFog` 和 `MI_NinjaGlobalFog`。输入与原有 Finish 使用项目现有资产；材质槽位可在高级参数中更换。

命令行重新构建材质时，先关闭编辑器，再运行 `Plugins/YogVision/Resources/BuildNinjaGlobalFog.py` 的 PythonScript commandlet。脚本只保存上述两个新材质，并保留已有全局实例参数；不会保存旧关卡或修改 Ninja 原始资产。

当前验证目标是项目的透视俯视相机。正交投影及 AfterDOF / AfterMotionBlur 透明特效的独立雾衰减尚未作为支持项验收。全局覆盖增加了可见雾范围，性能需要单独采样，不沿用旧容器版本的计时结论。
