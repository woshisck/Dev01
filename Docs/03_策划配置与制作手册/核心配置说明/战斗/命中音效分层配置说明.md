# 战斗音效配置说明

## 作用

战斗音效目前分为两个**互相独立**的部分：

| 部分 | 触发时机 | 配置对象 | 说明 |
| --- | --- | --- | --- |
| 挥击音效 | 每次挥砍，**挥空也响** | `UWeaponDefinition` | 攻击方，回答「挥的是什么武器」 |
| 命中反馈 | 仅命中时，每个受击目标一次 | `UEnemyHitImpactData` | 受击方，回答「打在什么上」 |

两者**不在同一帧发生**：挥击音效在蒙太奇的挥砍弧线上播放，命中反馈在伤害判定命中后播放。它们不叠加成一个复合音，是先后两个事件。

受击方用一张表解决「武器种类 × 敌人材质」的组合爆炸：材质分为 Soft / Hard / Immaterial，成本是 `材质数 × 冲击等级数`，加新武器不需要补音效。

> **待开发**：攻击方目前没有「命中瞬间」的音层，命中音完全由受击方提供。远程命中路径不走 `PlayHitFeedback`，枪的命中音效尚未接通。敌人攻击玩家时只有受击方层。

## 挥击音效（攻击方）

### 配置字段

`UWeaponDefinition` → `Combat|Whiff` 分类：

| 字段 | 显示名 | 说明 |
| --- | --- | --- |
| `WhiffSound` | 挥击音效 | 该武器的挥砍音源。留空则挥砍无声 |
| `WhiffSoundVolume` | 挥击音量 | |
| `WhiffSoundPitch` | 挥击音调 | |

### 摆放方式

在攻击蒙太奇**挥砍弧线的峰值处**放一个 `AN Weapon Whiff Sound`（`UAN_WeaponWhiffSound`）。这是单点 Notify，不是区间 NotifyState。

```text
攻击蒙太奇时间轴：

  前摇          挥砍弧线        收招
  |------------|==============|---------|
                     ▲
                   AN Whiff
                   播放，之后不再管

音源自带衰减尾巴 ────────►
```

触发时读取当前装备武器的 `WhiffSound` 并播放（挂在角色 Mesh 上，跟随移动）。

每条攻击蒙太奇都要单独摆一个，摆在弧线峰值而不是前摇起点——摆太早会听起来像提前发力。

### 注意事项

- **与命中判定完全无关。** 挥空同样会响，这正是它存在的意义（改动前挥空是完全没有声音的）。
- **Fire-and-forget，没有淡出。** 衰减尾巴必须**做进音源本身**。蒙太奇被冲刺取消或打断时，尾巴会自然响完，不会被掐掉。所以不要用持续型/循环型音源，只用自带衰减的一次性音源。
- **音源建议 150-400ms**，带明显的空气感起伏，才能听出弧线和重量。
- **高攻速下相邻两刀的尾巴会重叠**，这是正常的，听起来更急促。但同一音源如果做得过长（>600ms），连招时会糊成一片。
- **目前仅玩家生效。** 敌人没有 `UWeaponDefinition`，摆了 Notify 也不会响。
- **空手状态可用。** 取值走 `GetEffectiveEquippedWeaponDefinition`，空手时回落到 `DefaultUnarmedWeaponDef`。

## 命中反馈（受击方）

### 配置位置

| 项 | 配置对象 | 路径 |
| --- | --- | --- |
| 反馈表 | `UEnemyHitImpactData` | `Content/Data/Combat/DA_EnemyHitImpact`，由 Project Settings → Game → Yog → Combat 引用 |
| 敌人材质标签 | `UHitImpactVisualComponent` | 敌人蓝图 → `Combat\|Hit Impact Visual\|Hit React` → `HitReactMaterial` |

受击方**只有一张表**。材质、Buff 状态、护甲全部走同一份 `Entries`，用 GameplayTag 匹配 + `Priority` 排序，不存在第二张覆盖表。

`UHitImpactVisualComponent` 由 `AYogCharacterBase` 在构造时创建，是每个角色都有的原生组件，**不需要手动添加**，只要设 `HitReactMaterial` 即可。留空会回落到 `HitReact.Material.Soft`（不是静音）。

### Entries 与级联规则

每条 `Entries` 是一条规则：「当受击者身上有 `MatchTag` 时，贡献这份反馈」。

命中时的解析流程：

1. 收集受击者的标签集合 = `HitReactMaterial` + ASC 上所有标签 +（`ArmorHP > 0` 时自动补 `Buff.Status.Armored`）。
2. 取出所有 `MatchTag` 命中的条目，按 `Priority` 从高到低排序。
3. **每个字段各自独立地，从高优先级往下取第一个「填了的」值。**

第 3 条是关键：高优先级条目可以只填 VFX，声音自动继承下层材质条目的。

```text
受击者标签 = { HitReact.Material.Hard, Buff.Status.Poisoned }

  Buff.Status.Poisoned    Priority 50
    Sound: (空)      VFX: NS_PoisonHit
  HitReact.Material.Hard  Priority 10
    Sound: SW_HardHit    VFX: NS_Sparks

  最终结果：Sound = SW_HardHit    （Poisoned 没填，级联到下层）
            VFX   = NS_PoisonHit  （Poisoned 优先级高，胜出）
```

### 字段说明

| 字段 | 说明 |
| --- | --- |
| `MatchTag` | 匹配标签，可填 `HitReact.Material.*` 或任意受击者会持有的状态标签（`Buff.Status.*`）。父标签会匹配所有子标签 |
| `Priority` | 数值越大越优先。相同数值按数组顺序，建议保持数值互不相同 |
| `Levels` | 强度档数组，由攻击方武器的 `HitImpactLevel` 选择（1 起，越界自动 Clamp）。留空则本条只贡献震屏 |
| `CameraShakeLevel` | 震屏等级，`0` = 不贡献。取级联中第一个非 0 值 |

`Levels` 每条包含 `Sound` / `SoundVolume` / `SoundPitch` / `VFX` / `VFXScale` / `VFXRotationOffset`。

`HitImpactLevel` 配在 `UWeaponDefinition` → `Combat|Hit Feedback`，是武器上的常量，不随单次命中变化。

## 震屏（CameraShakeLevel）

### 解析链路

```text
Entries 级联，取第一个非 0 的 CameraShakeLevel
        │
        ▼
每个受击目标各返回一个等级
        │
        ▼
GA_MeleeAttack 取所有目标的最大值（不是累加）
        │
        ▼
AYogPlayerCameraManager::PlayShakeLevel(等级)
        │
        ▼
UYogSettings.CameraShakeLevelTable → DT_CameraShakeLevels 查表
        │
        ▼
FCameraShakeLevelRow.ShakeClass + Scale → 实际播放
```

一次挥击**只震一次**。命中 5 个敌人取其中最高等级，不会叠成 5 次震动。

### DT_CameraShakeLevels 当前内容

| 行名 | Level | ShakeClass |
| --- | --- | --- |
| `HeavyAttack` | 1 | `B_CameraShakeBase` |
| `CriticalHit` | 2 | `B_CameraShake_UltraSword` |

`Entries` 里填的 `CameraShakeLevel` 必须能在这张表里查到对应 `Level`，否则不震。新增等级要先在 `DT_CameraShakeLevels` 加行。

### 材质条目必须留 0

材质条目会命中**每一次**普通攻击，所以：

- 三条 `HitReact.Material.*` 条目的 `CameraShakeLevel` **保持 `0`**，除非确实想让每一次普通命中都震屏。
- 震屏只配在需要强调的状态条目上（护甲弹开、无敌、招架）。
- 忘记这一点最典型的表现是「打小怪也一直在震」。

### 与其他震屏来源的关系

震屏还有另外两个独立来源，配置时注意不要叠加过量：

| 来源 | 配置位置 | 说明 |
| --- | --- | --- |
| 受击方条目 | `DA_EnemyHitImpact.Entries.CameraShakeLevel` | 本文所述，按受击者标签 |
| 攻击表现 Cue | `UHitCueData.CameraShakeLevel` / `CritCameraShakeLevel` | 按攻击动作 / 是否暴击 |
| 全局伤害缩放 | `UYogSettings.HitShakeConfig` | `UHitCueData` 等级为 `0` 时的兜底，按伤害值缩放 |

三者会各自独立触发。同一次命中若三处都配了，玩家会收到多次震动。

## 推荐配置

| 项 | 推荐值 |
| --- | --- |
| 挥击音效时长 | 150-400ms，带空气感起伏，衰减尾巴做进音源 |
| 材质层时长 | 150-400ms，尾巴由本层负责 |
| 材质条目 `Priority` | `10` |
| 状态条目 `Priority` | `50`（中毒、流血等）／`80`（护甲）／`100`（无敌、招架） |
| 材质条目 `CameraShakeLevel` | `0`（必须，否则每次普通命中都震屏） |
| 状态条目 `CameraShakeLevel` | `0` 起；只在护甲弹开一类需要强调的条目上填 `1` |

挥击音效每把武器做一条即可，不需要按材质或强度分档——武器辨识度主要靠这一条承担。

## 配置示例

`DA_EnemyHitImpact.Entries` 最小配置：

| MatchTag | Priority | CameraShakeLevel | 内容 |
| --- | --- | --- | --- |
| `HitReact.Material.Soft` | 10 | 0 | 湿润挤压破裂声 |
| `HitReact.Material.Hard` | 10 | 0 | 带余振金属撞击声 |
| `HitReact.Material.Immaterial` | 10 | 0 | 空气感嗡鸣扩散声 |
| `Buff.Status.Poisoned` | 50 | 0 | 只填中毒 VFX，声音级联继承材质层 |
| `Buff.Status.Bleeding` | 50 | 0 | 只填流血 VFX，声音级联继承材质层 |
| `Buff.Status.Armored` | 80 | 1 | 硬质弹开声，压过材质层，附带震屏 |

## 验收方式

### 挥击音效

1. 在攻击蒙太奇挥砍弧线峰值处摆好 `AN Weapon Whiff Sound`，武器 DA 填好 `WhiffSound`。
2. **对空挥砍**，确认有声音。这是本次改动新增的能力，改动前挥空是静音的。
3. 砍中敌人，确认挥击音之后能听到受击方的材质音，两者是先后关系不是同时。
4. 快速连招 3 段，确认是三次独立挥砍音，没有重叠嗡鸣。
5. 挥砍中途冲刺取消，确认挥击音淡出而不是拖着响完。
6. 场上两个敌人同时攻击 + 玩家挥砍，确认各自的挥击音互不打断（状态存在角色上，不在 Notify 上）。
7. 空手状态攻击，确认不崩溃；`DefaultUnarmedWeaponDef` 填了音源则会响。

### 命中反馈

8. 打开 `DA_EnemyHitImpact`，确认 `Entries` 可编辑，`MatchTag` 选择器能选到 `HitReact.Material.*` 和 `Buff.Status.*`。
9. 打开 `B_EnemyBase`，确认 `HitReactMaterial` 下拉只列出 `HitReact.Material.*`。
10. 用同一把武器打不同材质的敌人，确认能听出材质差异。
11. 给敌人挂中毒（`GE_Poison`）后命中，确认中毒 VFX 生效，同时材质声音仍然通过级联播放。
12. 打护甲状态（`ArmorHP > 0`）的敌人，确认走到 `Buff.Status.Armored` 条目。

### 震屏

13. 连续平砍普通小怪 10 次，确认**完全不震屏**（材质条目 `CameraShakeLevel` 都是 `0`）。这是最容易踩的回归点。
14. 一次挥击命中 3 个以上带震屏条目的敌人，确认只震**一次**（取最大值），不是每个目标震一次。
15. 在某条目上把 `CameraShakeLevel` 填成 `DT_CameraShakeLevels` 里不存在的等级，确认不震且不报错。

## 注意事项

- **护甲是属性不是标签。** `ArmorHP > 0` 时由 `UHitImpactVisualComponent` 自动补 `Buff.Status.Armored` 到匹配集合，不需要任何 GE 授予该标签。反过来说，如果以后真的有 GE 授予了它，两者会指向同一条目，不会冲突。
- **`Buff.Status.Invulnerable` 当前没有任何来源授予**，配了条目也不会命中。等实际有 GE / FA 授予后再配。
- **枪的枪响不在这里配。** 枪口爆音在开火时由 `AN_FireProjectile` 在武器位置播放。
- **`DA_EnemyHitImpact` 必须在 Project Settings 里挂上。** 没挂的话 `PlayHitFeedback` 会直接返回，命中完全静音且不报警告。
- 旧的 `DT_BuffHitFeedback` 表和 `EHitReactTier` 枚举已移除，配置全部迁移到 `Entries`。
- 旧的攻击方「命中瞬态」层（`ImpactTransientSound`）及其 `bSuppressWeaponTransient` 开关已移除，字段改为挥击音效。原先在 `DA_WPN_THSword` 上配的瞬态音源需要重新指定为挥击音源。
